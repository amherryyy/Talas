## Project overview

Duno is a one-month, browser-based study-planning MVP. Students manage subjects and topics, find topics, see explainable priorities, make an adjustable daily plan, time and save study sessions, review descriptive Aralytics summaries, print a report, and read curated study suggestions. Optional workload and energy check-ins stay private to the student. Admins see aggregate totals only.

The approved user-facing areas are **Duno Focus**, **Duno Plan**, **Duno Guide**, and **Duno Timer**; the existing name **Aralytics** remains. The approved stack is CodeIgniter 4.7.5, Shield 1.4.1, PHP, MySQL/MariaDB, server-rendered views, CSS, and small plain JavaScript modules. The deployment target is InfinityFree free hosting by FTP/FTPS. Do not add AI advice, grade prediction, native apps, background workers, or other out-of-scope features.

The current remote `main` snapshot contains the starter/auth foundation, F-03 through F-13, and merged CI automation. F-03 through F-10 have recorded owner acceptance and merges through PR #5; F-11 through F-13 and restart/package work are included in PR #9. PRs #7, #9, and #10 are merged. Local schema/migration work and local auth review are documented. The hosted initial schema import is owner-reported as complete (15 tables, nine migration rows). The owner reports R-04 is all good; earlier evidence for the homepage/assets, student auth, admin dashboard, student denial of the admin route, and private-path denials is recorded in [`deployment.md`](deployment.md).
