# Duno acceptance verification plan

**Status:** Planned checks; none of the cases below are recorded as newly executed by this document.

**Authority:** Owner-approved functional requirements F-01 through F-15 and security requirements S-01 through S-10 in [`requirements.md`](requirements.md). The aligned SRS and survey inform context but do not override the approved baseline. ISO/IEC 25010 evaluation remains pending; this plan is not an evaluation result.

**Test data:** Use synthetic student accounts A and B, a separate synthetic admin, and synthetic study records only. Never use real student data or production credentials. Run database and role-boundary checks against the approved local/review environment or a prepared staging site, not against live production data.

## How to record results

For each case, record the source revision, environment, browser/device, database migration state, date, tester, result (**Passed**, **Failed**, **Not run**, or **Not applicable**), evidence location, and defect/reference. A code path or historical test is not a fresh acceptance result. A host-generated 403 prevents the affected live checks and must remain **Not run / blocked** until the application is reachable.

## Release and quality evaluation gates

Before accepting a release, attach relevant unit/feature results, PHP syntax/style results, dependency audit, manual phone/tablet/desktop observations, cross-owner evidence, migration ledger/schema state, reviewed package inventory, release marker, and host smoke/security results. Separate results by environment; do not substitute local success for host acceptance.

For the approved SRS quality evaluation, prepare a separate protocol before collecting ratings or claiming ISO/IEC 25010 conformance. Record the selected edition and relevant characteristics, instrument and questions, participant/sample method, test tasks/environment, measures and acceptance criteria, consent/privacy handling, analysis method, and result limitations. Survey preferences are not product acceptance, and evaluation is still pending.
