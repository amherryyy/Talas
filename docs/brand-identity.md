# Duno brand identity

## Approved identity

- **Wordmark:** `duno.` (lowercase, including the period)
- **Tagline:** `Your Little Study Buddy.`
- **Mascot:** a friendly Eureka lightbulb wearing a traditional Filipino salakot.
- **Product areas:** Duno Focus, Duno Plan, Duno Guide, and Duno Timer.
- **Existing feature:** Aralytics. Keep this name.

## Color tokens

| Token | Hex | Use |
| --- | --- | --- |
| Purple | `#7465D8` | Main brand color and primary actions |
| Mint | `#B9E8D1` | Supportive highlights and calm success surfaces |
| Gold | `#FFDA92` | Small warm accents and mascot details |
| Canvas | `#F7F6FC` | Main page background |

Use a dark, high-contrast text color with the palette. Keep keyboard focus visible and honor reduced-motion preferences.

## Mascot states and asset requirement

Plan five lightweight states: **happy**, **thinking**, **focused**, **celebrating**, and **resting**. Mascot motion is decorative and must not carry essential information. Provide a static fallback and respect `prefers-reduced-motion`.

The referenced AppDev conversation exposed no image attachment, and no approved mascot source file was present in the active repository. Do not redraw or replace the approved art using a web-search result. Required export: a transparent SVG of the approved lightbulb-and-salakot character, plus matching artwork for the five states (separate SVGs or a documented sprite sheet). Use a transparent PNG fallback only if vector export is unavailable. Keep the mascot artwork out of the UI until this approved export is supplied.

## User-facing naming

Use `duno.` and its tagline in shared brand areas. Use the four product-area names exactly as listed above. Retain **Aralytics**. The `Talas` folder name and historical proposal references may remain for repository compatibility and project history; do not show Talas in new or rebranded UI. Do not rename database tables, migrations, routes, or stored identifiers as part of the visual rebrand.
