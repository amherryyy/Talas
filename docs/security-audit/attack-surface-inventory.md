# Attack Surface Inventory

**Snapshot:** Local `main` plus the uncommitted changes present on 2026-11-02. Secrets and runtime data were excluded. This inventory is based on source inspection; host behavior is identified separately.

| Surface | Components | Threats / sensitive assets | Existing protections and evidence | Remaining verification |
|---|---|---|---|---|
| Public pages and language preference | `app/Config/Routes.php`; Home, About, Legal, LanguagePreference | Reflected input, open redirects, preference-cookie tampering | Auto-routing disabled; language values allowlisted; return path parsed and restricted to app-local paths; CSRF applies globally; views use `esc()` | Browser check and unusual return-path cases |
| Registration, login, activation, logout | Shield routes; `app/Config/Auth.php`; `RegistrationEmailActivator`; `RegistrationRecovery`; auth abuse and consent filters | Account takeover, role escalation, enumeration, brute force, session fixation | Shield session auth; student is default server-assigned group; registration consent filter; registration email activation; activation code expiry/attempt/send limits; custom endpoint throttles; Shield `auth-rates`; logout is POST; remember-me and magic links disabled; Shield regenerates session ID on login | Host rate-limit store and email delivery behavior; session cookie over live HTTPS |
| Password recovery | `PasswordRecovery`; `PasswordResetCodeModel`; migration `2026-11-02-000001_CreatePasswordResetCodes` | Account takeover, code brute force/reuse, account enumeration, mail abuse | Neutral response; active accounts only; six-digit `random_int`; hash-at-rest; 15-minute expiry; five failed attempts; one-time atomic consume inside password change transaction; old codes removed; endpoint rate limits; reset tests passed | SMTP delivery and response-time side channel not measured; live migration status not confirmed |
| Student workspace | `/student/*`; student controllers and models | IDOR/BOLA, unauthorized write/delete, cross-owner or cross-program access | Session, exclusive student role, and program filters; fixed routes; owner-scoped model queries and nested owner checks; composite owner constraints documented; feature suite passed, including foreign subject/topic/session/plan/check-in cases | Repeat on exact hosted release for POST/update/delete and forged foreign references |
| Private check-ins | CheckIn controller/model, Aralytics and admin summary services | Disclosure of individual workload/energy ratings | Owner-scoped CRUD; server-side 1–5 validation; values marked sensitive in exception traces; excluded from admin totals and reports except student’s own private summary; cross-owner tests passed | Verify host exact release and logs/error behavior |
| Administrator | `/admin/*`; Admin Dashboard and summary service | Student privilege escalation or exposure of identifiable/student-level data | Session, exclusive admin role, `admin.access` permission; only aggregate dashboard route; small-cohort chart suppression tests exist; student/admin separation tests passed | Exact live role and aggregation behavior on r9 |
| Forms and output rendering | Server-rendered views; POST handlers; plain JS | CSRF, SQL injection, stored/reflected XSS, mass assignment, parameter tampering | Global session CSRF; explicit routes; framework validation; CodeIgniter query builder/models; model `allowedFields`; HTML output predominantly escaped with `esc()`; no upload/download routes found | Manual browser/XSS probe not performed; review future templates and query additions |
| Sessions and browser state | CI session/cookie/security configuration; dynamic response filter | Session theft/fixation, stale private pages, insecure cookies | Two-hour session expiry; production Secure cookie; HttpOnly; SameSite=Lax; Shield login regeneration and logout; `noCache()` on dynamic responses; local production `/terms` response emitted CSP, HSTS, no-store, and SecureHeaders | Live Set-Cookie and header behavior through InfinityFree TLS/proxy; logout/back-button behavior; browser CSP compatibility |
| PWA and offline recovery | `public/sw.js`, manifest, offline page, `public/assets/js/pwa.js` | Offline exposure of authenticated pages or queued writes | Explicit public static allowlist; only GET/same-origin; navigations go to network then static offline page; worker does not intercept POST; caches only successful basic responses without private/no-store header; no localStorage/sessionStorage use found for study records | Repeat cache inventory and offline navigation on r9/browser matrix |
| Deployment and private paths | Source `.htaccess`; app/writable deny files; `scripts/Build-InfinityFreePackage.ps1`; front controller | Exposed `.env`, source, dependencies, backups, debug traces, stale package | Source-root denies common private paths including `build/` and dotfiles when rewrite is active; package generator emits stricter root deny rules and excludes `.env`, tests, docs, tools and backups; production boot disables displayed errors and production DB debug is off; deployment evidence documents earlier 403 probes | `/.env` HTTP status remains unverified in existing evidence; probe source-root `build/` denial and confirm r9 parity, host module behavior, and response headers |
| Dependencies and integrations | `composer.json`/lock; CI4 4.7.5 and Shield 1.4.1; SMTP configuration | Known dependency vulnerabilities, mail credential exposure | Versions locked; `.env` ignored; deployment packager removes Composer manifests and excludes local `.env`; logs contain generic mail-failure text | No current `composer audit --locked`; actual secret placement and SMTP configuration are not inspected or repeated |
| File handling | No application upload/download routes identified | Malicious upload, path traversal, private-file disclosure | No file upload/download feature found in routes/controllers. Static public assets are built from repository assets | Reassess if file features are added |

## Data handled

Account identifiers and password identities; selected academic program; subjects, topics, due dates/progress/difficulty; plans; study sessions; progression/streak values; optional private workload and energy ratings; short-lived registration and password-reset codes. No production secret value or actual student record was copied into this report.

## Route map

- Public: `/`, `/about`, `/terms`, `/privacy`, `/cookies`, `POST /language`.
- Authentication: Shield registration/login/action routes; registration recovery resend/cancel; forgot/reset password GET and POST routes; `POST /logout`.
- Student: academic-program selection, profile and deletion, subject/topic CRUD and imports, priority, plan generation/edit actions, sessions, Aralytics, and check-ins under the `student` group.
- Administrator: aggregate dashboard under the `admin` group.
- Auto-routing is disabled. Student/admin route groups apply session plus role checks; admin also applies `admin.access`.
